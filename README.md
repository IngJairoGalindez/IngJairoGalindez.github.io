# Portafolio Profesional - Jairo Galindez Mahecha

![Logo Felino Ingeniería](assets/logo-feline.png)

Portafolio web oficial de **Jairo Galindez**, Ingeniero Electromecánico especializado en soluciones robustas para el sector industrial, telecomunicaciones y comercial.

## 🛠 Tecnologías Utilizadas

- **HTML5 & CSS3**: Estructura semántica y diseño moderno (Cyber-Industrial).
- **JavaScript Vanilla**: Lógica de modales, galería dinámica interactiva y filtros.
- **FontAwesome**: Iconografía.
- **AOS.js**: Animaciones de scroll fluidas.
- **GitHub Pages**: Despliegue y hosting.

## 🚀 Características del Proyecto

- **Diseño Mobile-First**: Totalmente adaptable a cualquier dispositivo (móvil, tablet, escritorio).
- **Catálogo de Proyectos Interactivos**: Galería con filtros por categoría y visor de imágenes en formato "Lightbox" con animaciones y soporte para WhatsApp.
- **Identidad Visual**: Uso de modo oscuro tecnológico (neon cyan y deep slate) con un distintivo perfil felino geométrico que proyecta agilidad y solidez técnica.
- **Formulario Integrado**: Formularios de captura de datos orientados a marketing y cotizaciones directas.

## 📂 Estructura del Proyecto

```text
/
├── index.html        # Landing page y resumen de servicios
├── catalogo.html     # Galería completa de proyectos
├── formulario.html   # Formulario de cotización / contacto
├── style.css         # Hoja de estilos central (Diseño Cyber-Industrial)
├── main.js           # Scripts de modales, filtros y Lightbox
└── assets/           # Directorio de imágenes, fotos de proyectos y logo
```
